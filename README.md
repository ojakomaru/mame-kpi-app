# mame-kpi-app（目標管理アプリ）

習慣・目標（KPI）を登録し、日ごとの達成を記録する Java / JSP の Web アプリです。学習・ポートフォリオ用に作ったもので、**インターネットに公開して運用する想定ではありません**。

## 注意
- ログイン機能はありません。公開サーバーに置かないでください。
- 使っているライブラリ（MySQL ドライバ 8.0.31、Jackson 2.14.0 など）は更新していません。
- 設計は [APP設計書.md](APP設計書.md) を参照してください。

## 技術
Java（Servlet / JSP、Jakarta EE 5）、MySQL、Tomcat 10 系、JSTL

## 動かし方（手元）
1. MySQL に `habit` データベースを作り、[APP設計書.md](APP設計書.md) のテーブル定義でテーブルを作る。
2. `META-INF/context.xml.sample` を `META-INF/context.xml` にコピーし、ユーザー名とパスワードを自分の値にする（このファイルは Git に入れない）。
3. Tomcat 10 系にデプロイして `/` を開く。

## 安全面で直したこと
- SQL を `?`（プレースホルダ）方式に統一。並べ替えの列名・向きは許可リストで検証。
- DB のパスワードをリポジトリから除去。
